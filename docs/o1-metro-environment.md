# O1 潮没末班线环境与敌人批次

本批将“潮没末班线”从程序矩形、网格和继承疗养院角色贴图的灰盒状态，推进为可直接游玩的独立视觉世界。玩法布局、碰撞、潮位、双路线、任务和剧情逻辑保持不变。

## 正式资产

| 资产 | 规格 | 运行时用途 |
|---|---:|---|
| 地铁 TileSet | 8×8，32×32 Tile | 站台、轨道、墙体、楼梯、积水和破损转角 |
| 地铁 Prop Atlas | 4×3，128×128 | 闸机、长椅、道岔、水闸、列车门、信号柜和档案终端 |
| 溺行者 | 6×4，48×64 | Down / Left / Right / Up 六帧移动 |
| 检票员 | 6×4，48×64 | 四方向移动与闸机拦截轮廓 |
| 信号锚 | 6×4，64×64 | 四方向/旋转状态与六帧信号脉冲 |

## 生成提示摘要

所有素材使用 OpenAI 内置图像生成，参考仓库内疗养院 Tile 与护理员 Sprite 的像素密度和 3/4 俯视角。环境提示锁定湿冷蓝灰、信号琥珀、污水黑、褪色公共交通设施和“仍在运行的失效秩序”；角色提示分别锁定水压拖拽的通勤者、与闸机结构融合的检票员，以及轨道继电器构成的信号锚。

母版使用纯 `#FF00FF` 色键背景。进入仓库前由 `tools/process_o1_metro_assets.py` 完成固定网格裁切、色键与紫边清理、128 色限制和透明 PNG 输出。

## 接入约束

- 地铁全图先铺 Tile，再绘制区域、潮水、墙体和 Prop。
- 潮水必须使用水面 Tile，边框仅保留为玩法危险提示。
- 任务物按 RECORD / POWER / EXIT / FLOODGATE / NPC / SECRET 映射到地铁 Prop。
- 溺行者与检票员不得继续读取疗养院角色贴图。
- 信号锚正常路径必须使用 `Sprite2D`；程序圆环仅作为资源异常兜底。
- 车长回声仍在下一批完成，避免本批同时改变地图、普通敌人与 Boss。
