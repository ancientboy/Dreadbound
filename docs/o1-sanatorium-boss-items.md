# O1 第四批：疗养院首领、遗物与拾取物

本批完成废弃疗养院的核心首领与物品视觉闭环。所有新资产继续遵循 `docs/art-style.md` 的冷暗、衰败、低分辨率恐怖像素语言，并保持现有战斗、掉落、成长与结算事实不变。

## 已接入范围

- 缝合主任：96×96 源帧，方向行序 `down / left / right / up`，每方向 6 帧。
- 主任的缝合镰：0–5 级共 6 个 64×64 持握外形；玩家装备后替换程序线段轮廓。
- 疗养院装备图标：回响切割器、旧医疗铭牌、镇静线圈、病房回响体。
- 首领遗物图标：主任的缝合镰。
- 疗养院材料图标：组织样本、病历残页、缝合核心。
- 世界拾取物：绷带、回响碎片、手枪弹药、霰弹、镇静剂、兴奋剂、组织样本、病历残页。
- 任务装置：病历终端、供电发电机、撤离信标绑定上一批疗养院 Prop。
- 异常回收箱：64×64 正式世界 Prop。
- 疗养院过道：地图底层先铺 32×32 正式通道地面，房间、墙体和 Prop 再按层覆盖。
- 任务与灯光图集：实验记录终端开关状态、最终出口开关状态、像素手电锥、损坏长灯、交互光圈和撤离光束。
- 移动残影：仅回响系路径保留短时残影，普通移动和其他路径不再持续拖影。

## 运行时规则

缝合主任使用 `Sprite2D` 的 6×4 固定帧管理。移动方向决定行，移动时间决定列；受伤和二阶段仅改变调制色，不改变碰撞、生命、攻击半径或历史变体。资源异常时仍保留原程序绘制的可见 Boss 轮廓。

主任的缝合镰按成长等级读取 6 格图集，并跟随玩家四方向持握。装备、材料、拾取物和任务装置均保留原有文本标签与交互反馈，以免像素图标成为唯一信息来源。

## 生成与整理

五张生产母版使用内置 OpenAI image generation 定向生成：

1. 缝合主任 6×4 四方向母版。
2. 主任的缝合镰 0–5 级成长母版。
3. 疗养院装备、材料与回收箱 3×3 图标母版。
4. 世界拾取物 4×2 母版。
5. 疗养院任务装置与像素灯光 4×2 母版。

生成时以护理员、阈值司仪、疗养院 Prop 和基础装备图标作为风格参考，使用纯洋红色键背景。`tools/process_o1_batch4.py` 负责分格、色键移除、固定尺寸、透明边缘清理、128 色限色和 PNG 优化。

所有资产当前为 `review`。桌面与手机横屏真实试玩确认 Boss 比例、持握方向、交互遮挡和拾取物亮度后，才升级为 `approved`。
