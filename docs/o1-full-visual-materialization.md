# O1 全量视觉素材化收尾

本批按 P0、P1、P2 顺序补齐此前未进入资产清单的运行时视觉，并在所有批次验证完成后统一发布。

## P0：战斗与掉落

- `sanatorium_enemy_skills.png`：4×2、每格 128×128。病患、爬行者、护理员与缝合主任的八种攻击/阶段 VFX。
- `advanced_weapons.png`：5×1、每格 64×64。回响切割器、绝缘撬棍、零点标记枪、围城火力核心、失控回响刃。
- `boss_evolution_weapons.png`：3×2、每格 128×64。缝合镰与导轨枪各三条最终进化分支。
- `materials_enemy_affixes.png`：5×2、每格 64×64。四种世界材料掉落物与六种敌人词缀附着层。

几何攻击预警、枪械弹道、光锥、血条和小地图继续程序绘制；它们承担实时可读性，不以复杂图片替代。

## P1：职业、成长与状态

三个职业分别使用一张 `4×4` 流派形态图集。行是该职业四个流派，列固定为下、左、右、上。形态只提供肩部、背部、挂具和异常轮廓，玩家职业本体仍负责四方向六帧动画。

三个职业分别使用一张 `4×4` 技能图集。行是四个流派，列是蓄势、形成、爆发、消散四帧。运行时按事件进度选帧，不再只缩放或旋转一张静态图。

`progression_status_icons.png` 为 6×3、每格 32×32：

1. 六种装备词条。
2. 六种心相。
3. 应急屏障、交替校准、异化压力、冻结、麻痹、弱点标记。

装备词条显示在仓库与合成候选卡右上角；心相显示在职业页；当前路径状态显示在副本 HUD。

## P2：剧情与成长反馈

- 六名角色拥有 192×192 对话头像：阈值司仪、沈岚、周衡、林雾、许照、无票者七号。
- 失踪乘客维护层使用八格独立地板、墙体、门、档案终端、排水、信号板和工作台模块。
- 两个世界各有三张阶段性档案图，随撤离和 Boss 进度显示。
- Boss 击败、职业锚定、流派解锁、心相形成使用四种短时全屏反馈。

## 生成与处理

正式母版由 OpenAI image generation 定向生成，现有角色、武器、VFX、地铁环境与 UI 图集仅作为原创项目内部风格参考。生成母版位于仓库外，不提交。

`tools/process_full_visual_materialization.py` 对每格自动识别洋红或绿色键色，执行分格、去色键、边缘去溢色、固定锚点、128 色限色和原子写入。正式 PNG 全部具有透明通道，代码按固定尺寸与索引加载。

## 验收

- 每张新图集尺寸、透明通道、非空格子与键色残留进入自动测试。
- P0 必须从敌人攻击、装备、掉落与词缀真实入口触发。
- P1 必须按朝向与事件进度选取不同格子。
- P2 必须在对话、隐藏区域、档案页与成长事件中显示。
- Web 正式包保持低于 80 MB 建议上限。
