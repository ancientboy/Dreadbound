# K0–K4：持续叙事副本

Dreadbound 的副本不再在每次投送时完全重置。地图、NPC、Boss 和唯一物品会保存玩家造成的关键变化；再次进入同一世界时，加载的是该世界的下一章。

## K0：副本记忆

`PersistentDungeonState` 为每个世界保存：

- 进入与成功撤离次数；
- 当前章节、首次结局和下一剧情变体；
- 已开放的隐藏区域；
- 已完成的剧情事件；
- Boss 击败次数与演化阶段；
- 最近 48 条可追溯历史；
- 当前行动代码，防止重载重复增加访问次数。

存档版本为 v18。v17 及更早存档缺少该字段时自动生成默认副本记录，并从已有装备补登记唯一物品。

## K1：NPC 长期记忆

地图二新增失踪乘客“林雾”。她保存：

- 生死、伤势、位置和信任；
- 玩家留下的承诺；
- 最近一次结局；
- 后续作为等待者、向导、被收容者或残留回声出现的身份。

关键选择同时进入 `ActionLedger`，因此人性洞察、阵营后果和副本剧情引用的是同一条行为证据。

## K2：二刷与三刷剧情

“潮没末班线”当前包含首个三章闭环：

1. **无人报站**：承诺回来，或把林雾的位置交给秩序署。
2. **回来的人 / 征用名单**：兑现、失约、反悔救援或接受征用。
3. **失踪者有名字 / 没人替你忘记**：保存或抹除名单，面对或切断回声。

剧情由确定性状态图选择。AI 将来可以依据这些状态生成台词和总结，但不能改写 NPC 生死、隐藏区域、奖励或已结算事实。

## K3：唯一物品

统一注册表记录：

- 取得行动与来源副本；
- 取得时的副本访问周期；
- 当前持有者、销毁状态与转化目标。

当前唯一物品：

- 主任的缝合镰；
- 末班导轨枪；
- 林雾的失踪乘客通行牌。

Boss 遗物本体只会入库一次。再次击败同一 Boss 会推进遗物成长；任何异常重复提交会转化为回响碎片，不能生成第二件本体。

## K4：隐藏地图与章节扩展

地图二新增“失踪乘客维护层”：

- 首次进入时地图不显示且碰撞门封闭；
- 前置选择尚未兑现时，行动代码无法开门；
- 二刷完成对应剧情后移除真实碰撞门；
- 小地图和展开地图随后永久显示隐藏区域；
- 区域内部加载林雾、失踪者名单或残留回声；
- 行动档案明确显示区域为何开放，以及对应的历史选择。

以后制作大型史诗副本时，可以沿用同一结构增加章节、NPC 与区域，不再把跨局状态写进具体地图场景。
