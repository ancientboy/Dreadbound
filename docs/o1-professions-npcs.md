# O1 职业形态、技能 VFX 与剧情 NPC

本批补齐职业系统此前未进入视觉清单的运行时素材，并替换副本中把剧情 NPC 画成设施或通用矩形的占位路径。

## 职业本体

三套职业本体保持同一名行者的身份、身高与动作帧：

- 坚守者：救援外套、肩部护具、医疗包与苔绿色/冷青色识别。
- 武装师：工业挂具、工具带、非对称肩甲与氧化橙/黄铜识别。
- 共鸣者：破损长衣、异常导管、余响结构与紫色/浅青色识别。

每套图集为 `6×4` 帧格，每帧 `48×64`；方向行顺序固定为下、左、右、上。未锚定职业时继续使用漂泊者图集。

## 十二流派形态与技能

`combat_style_forms.png` 采用 `4×3`、每格 `128×128`，顺序与 `ExchangeEvolution.COMBAT_STYLES` 一致：

1. 屏障反击、濒死不灭、牺牲治疗、通道控制。
2. 弱点狙击、重火力压制、爆破陷阱、遗物改造。
3. 精神感知、异常摄取、回响召唤、异化形态。

形态图集负责改变肩部、背部、外套边缘和异常轮廓；职业本体负责稳定动画身份。`profession_skills.png` 使用相同顺序，分别在治疗、低生命受击、近战、手枪、霰弹、切换武器、移动感知和风险选择的真实触发点播放。

## 剧情 NPC

`story_npcs_idle.png` 为 `6×5` 待机图集，每格 `64×96`：

1. 沈岚：失忆病人，保留人类状态，不复用敌对病患。
2. 周衡：最后的护理员，保留人类状态，不复用异常护理员。
3. 林雾：失踪乘客与维护层向导。
4. 许照：携带钟表与工具的修表匠。
5. 无票者七号：半透明检票回声。

`ObjectiveInteractable` 按目标 ID 和章节标题选择人物。已经转化为“失踪乘客名单”的交互继续显示档案设施，避免用林雾人物替代名单。

## 生成与处理

资产由 OpenAI image generation 定向生成，使用现有漂泊者、病患、护理员与检票员图集作为像素密度和世界服装参考；母版为纯洋红键背景。`tools/process_o1_professions_npcs.py` 完成分格、色键移除、固定尺寸、128 色限色和 PNG 优化，生成母版不进入仓库。
