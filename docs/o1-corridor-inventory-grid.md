# O1 回廊资产与格子仓库

本批把终末回廊从“正式角色与设施摆在程序灰盒上”推进为完整的资产化整备空间，并把装备、材料入口改为适合图片资产的格子交互。

## 回廊空间

- 新增 `corridor_hub_atlas.png`：4×4、每格 128×128。
- 内容覆盖地板模块、上下墙缘、左右护栏、柱基、破损地板、司仪平台、两扇传说门、档案终端、服务器、唯一藏品容器、地图终端、锚定舱与整备台。
- 正常渲染不再绘制中央单色梯形灰盒。
- 地板模块先铺满可行走区域，再叠加墙缘、护栏、设施、门、角色与交互反馈。
- 旧 `corridor_props.png` 只作为资源异常时的可见兜底。

## 装备与材料

- 19 件装备均有独立 32×32 图标。
- 6 种材料均有独立 32×32 图标。
- 七个回廊独立入口使用 7×32×32 图标图集。
- 装备仓库使用自适应列数的可滚动格子；点击后显示 112×112 大图、品质、评级、槽位、属性、强化、进化与装备状态。
- 材料背包使用世界材料格子；点击后显示大图、数量、稀有度、分类、来源、用途与叙事解释。
- 未发现或未来扩展条目使用统一封存图标，不退回纯文字灰盒。

## 生成与整理

图像使用内置 OpenAI 图像生成，现有回廊 Tile、Prop、装备与材料图标仅作为风格参考。生产母版均使用纯洋红色键背景，再由 `tools/process_o1_corridor_inventory.py` 分格、去色键、清除分隔线、缩放、限制 128 色并输出正式 PNG。

## 验收

- 回廊正常渲染代码中不存在中央梯形 `draw_colored_polygon`。
- 新回廊图集为 512×512，功能入口图集为 224×32。
- EquipmentDatabase 的 19 个 ID 与 ExchangeEvolution 的 6 个材料 ID 均有可加载图标。
- 格子仓库与材料详情可在桌面和手机横屏尺寸下实例化、点击与滚动。
- 新 PNG 具有透明通道、非空有效区域且无强洋红色键残留。
