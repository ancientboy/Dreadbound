# O1 潮没末班线视觉收尾

本批将潮没末班线从“地图与敌人已资产化”推进到完整战斗视觉：

- 潮位 1 使用浅水表面；潮位 2 使用深水、浪头、水线和角色前景浸没层。
- 水层固定在房间 Tile 之后、墙体与实体之前绘制，禁止被地板覆盖。
- 溺行者、检票员、信号锚和车长回声使用地铁专属技能 VFX。
- 车长回声使用独立 96×96、四方向六帧 Boss 图集。
- 末班导轨枪使用 0–5 级 64×64 连续成长图集。
- 手电改为胸灯投射：保留低强度环境光与前方增强照明，不再占用持枪手。
- 路径状态使用离散像素 VFX；紫色异化光圈只在异化压力存在时显示。

## 生成与整理

母版使用 OpenAI image generation 定向生成，统一纯洋红色键背景。正式文件通过
`tools/process_o1_metro_finish.py` 完成分格、色键移除、透明阈值、128 色索引和固定尺寸输出。

生成提示分为五组：

1. 车长回声四方向 Boss 动画。
2. 末班导轨枪六级成长形态。
3. 八格地铁敌人与 Boss 技能 VFX。
4. 八格浅水、深水、浪头、水线、浸没与排水 VFX。
5. 胸灯、光锥及三路径状态 VFX。
6. `DREADBOUND` 透明像素字标。
7. 八格移动端触控图标。

## 验收

- 所有正式 PNG 必须具备透明通道且无强洋红色键残留。
- 角色与武器锚点保持 Nearest、固定脚底/握把位置。
- 二级潮位必须在低层房间内形成连续深水面，并遮住角色脚部。
- 手电与任何当前武器不得共享同一持握轮廓。
- 正常状态不显示大面积紫色圆环；异化压力存在时才显示碎裂紫色环。
- 首页导航必须显示正式 Logo；移动端按钮必须使用图标集并保留文字/冷却兜底。
