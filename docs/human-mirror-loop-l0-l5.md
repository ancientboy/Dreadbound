# L0–L5：Human Mirror Loop

本阶段把 Dreadbound 的核心循环收敛为：

> 高压选择 → 记录真实代价 → 世界与 NPC 长期变化 → 玩家查看依据 → 玩家可用下一局反驳。

## L0：体验与存档门禁

- 存档升级至 v19，旧档自动迁移并记录迁移健康状态。
- 行动结算、人性镜鉴、移动端终端均有固定入口。
- 人性时间线、异议与反证契约进入存档，重启不会丢失。
- 内容 JSON、知识条目和副本分支都有启动前校验。

## L1：人性镜鉴

回廊顶部新增独立“人性镜鉴”入口，展示六维倾向、样本、置信度、支持/相反证据、跨局变化与当前反证契约。玩家可对任何已有证据的维度选择“我不同意”，系统会生成一个可验证的下一局行为契约，而不是把旧判断作为身份标签。

## L2：行为科学知识

知识库由 8 条扩展为 40 条，覆盖损失厌恶、稀缺、权威服从、旁观者效应、内外群体、互惠与报复、承诺升级、沉没成本、道德许可、责任分散、控制感、压力、延迟折扣、公开/匿名行为、有代价帮助、测量误差与可证伪预测。每条保留来源、来源类型、适用维度与非诊断边界。

## L3：高压行为事件

两张副本各有至少四个数据化行为情境。记录项包括：

- 选择产生的资源、受伤和机会成本；
- 行为是否公开或匿名；
- 玩家当时持有的资源；
- 副本时间压力；
- 同一维度的支持与相反证据。

免费帮助、公开帮助与匿名且有代价的帮助不会再使用同一权重。

## L4：两张持续副本

废弃疗养院加入沈岚、周衡、二刷分支、隐藏病历室与动态 Boss 变体。潮没末班线除林雾外加入许照和无票者七号。Boss 名称、生命、伤害阶段和能力提示读取 NPC 生死、章节与既往击败次数。

危险与深渊行动加入可见怪物词缀：

- 精英、变异；
- 狂化、冻蚀、共鸣；
- 噩梦。

词缀同时改变名称、颜色、生命、伤害、速度、感知和额外掉落，不是纯文本前缀。

## L5：数据驱动内容

`content/dreadbound_content_zh.json` 保存副本章节、NPC、行为事件和怪物词缀；`ContentCatalog` 提供确定性读取与校验。新增内容应先进入数据文件，规则脚本只执行合法效果，避免大型史诗副本继续堆积硬编码。
