# V21：完整掉落、分类背包与回廊入口

## 掉落来源

- 普通怪按“世界 + 族群”读取独立掉落池，不再共享单一补给函数。
- 精英词缀和危险度提高总掉率；额外概率优先转化为所属世界的常见材料。
- 稀有材料连续六次未出现后进入保底：疗养院护理员对应病历残页，末班线检票员对应失效票根。
- Boss 必定暂存对应进化核心；成长唯一装备仍由 Boss 回收箱的难度概率决定。
- 隐藏区域、撤离勘探与后续容器使用同一个来源奖励目录，新增世界不需要复制掉落逻辑。

## 撤离规则

材料拾取后先进入本次行动暂存清单，只有成功撤离才写入永久材料背包。失败或主动撤回会失去暂存材料。结算同时保存最近 40 条材料掉落档案。

## 三类库存

| 库存 | 内容 | 容量与保护 |
|---|---|---|
| 装备背包 | 普通武器、护符、可合成装备 | 20 格；可装备、强化、进化、拆解 |
| 材料背包 | 六种世界材料与进化核心 | 不占装备格；每种 999 |
| 唯一藏品 | 剧情唯一物品、Boss 成长遗物 | 世界唯一注册；不可合成，重复奖励转化 |

## 回廊信息架构

回廊提供七个同级入口：装备、材料、唯一藏品、档案、职业、副本、终端。

- 装备：只负责装备管理、强化、进化、拆解和合成结果。
- 材料：显示数量、稀有度、分类、来源和用途。
- 唯一藏品：显示收集状态与成长遗物等级。
- 档案：行动结算、人性证据与长期副本记忆。
- 职业：职业锚点、节点和十二战斗流派。
- 副本：世界、难度和投送。
- 终端：异常兑换与合成发起。

桌面为单排导航，窄屏与手机自动变为两排四列，不再要求玩家进入一个长终端页面寻找所有操作。
