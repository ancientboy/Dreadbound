# O1 第三批：疗养院可玩美术与阈值司仪

本批继续执行 `docs/playable-alpha-o0.md` 的锁定规格，将废弃疗养院从灰盒区域推进到可试玩的正式视觉切片，同时修正基础近战反馈。

## 已接入范围

- 疗养院 8×8 Tile Atlas：地面、墙面、门洞、破损边缘、通风与管线。
- 疗养院 4×3 Prop Atlas：病床、药柜、帘架、发电机、档案桌、医疗门、推车和撤离信标。
- 爬行者：64×48，行序 `down / left / right / up`，每方向 6 帧。
- 护理员：48×64，行序 `down / left / right / up`，每方向 6 帧。
- 阈值司仪：96×96 源帧，回廊中按 128×128 呈现，约为行者视觉高度的两倍。
- 撬棍近战弧线：图集月牙的 authored axis 校正 180°，视觉开口与实际攻击方向一致。

## 视觉职责

阈值司仪不是战斗 Boss，但必须拥有接近 Boss 的画面权重。它采用宽肩礼仪外壳、长袍、无脸面罩与青色档案核心；站在回廊中央基座上，保持缓慢的六帧呼吸/悬浮节奏。角色不得替代终端或改变既有契约规则。

爬行者通过贴地横向轮廓表达高速近身威胁；护理员通过更宽、更重的直立轮廓表达慢速压迫与长前摇。两者均使用 `Sprite2D` 固定帧管理，并在资源异常时保留程序绘制轮廓。

## 生成与整理

五张生产母版由 OpenAI image generation 定向生成，使用既有病患 Sprite 与疗养院基准图作为风格参考。母版使用纯色键背景；`tools/process_o1_batch3.py` 负责色键移除、分格、缩放、透明边缘清理和固定尺寸输出。

所有资产当前为 `review`。只有桌面与手机横屏真实试玩确认比例、亮度、碰撞阅读和帧序后，才可升级为 `approved`。
