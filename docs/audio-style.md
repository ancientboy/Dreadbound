# Dreadbound：正式音频制作标准（O0 锁定）

## 1. 声音目标

Dreadbound 的声音不是背景装饰，而是玩家判断距离、风险、异常规则和撤离时机的第二套界面。

- 恐怖来自空间感、机械循环、远处事件与不完整的人声。
- 音乐克制，环境声保持长时间可听；战斗时不使用持续轰炸式高响度。
- 每类敌人必须能在离屏状态下通过脚步/呼吸/机械声区分。
- 重要交互同时具备视觉与声音反馈，不以声音作为唯一无障碍提示。

## 2. 技术规格

| 项目 | 制作母版 | Godot/Web 交付 |
|---|---|---|
| 采样率 | 48 kHz | 48 kHz |
| 位深 | 24-bit | 导入前保留 24-bit WAV |
| 音乐/长环境 | Stereo WAV | OGG Vorbis，循环 |
| 定位音效 | Mono WAV | Godot 位置音频 |
| UI/非定位提示 | Mono 或 Stereo WAV | 非位置音频 |
| Master 峰值 | 不高于 -1 dBTP | 总线限制 |

响度目标是混音起点，不是用硬限幅强行达到：

- 音乐：约 `-18 LUFS-I`。
- 环境循环：约 `-24 LUFS-I`。
- 战斗/交互音效组：约 `-18 LUFS-I`，保留瞬态。
- UI：约 `-20 LUFS-I`，不得刺耳。

循环文件必须在零交叉附近剪辑并经过至少 30 秒连续循环试听；禁止将明显混响尾部生硬截断。

## 3. 总线结构

`Master`

- `Music`
- `Ambience`
- `SFX`
  - `Combat`
  - `Creature`
  - `World`
- `UI`
- `Voice`

危险提示、Boss 预兆和撤离提示通过短暂侧链压低 Music/Ambience 2–4 dB，不能简单把提示音做得极响。设置页最终必须能够独立控制 Master、Music、Ambience、SFX 与 Voice。

## 4. 世界声音语言

### 终末回廊

低频结构共振、遥远继电器、无法定位的金属应力、稀疏青光脉冲。音乐以低持续音、处理过的玻璃/金属和极少旋律构成。

### 废弃疗养院

荧光灯、旧通风、轮子、输液滴落、纸张与远处布料摩擦。不要持续播放病人尖叫。Boss 使用缝线拉紧、病历翻页和手术器械节奏形成主题。

### 潮没末班线

水压、隧道风、轨道余振、失真广播、远处车轮和继电器。不同潮位改变低频与高频衰减；车次变化通过节拍和广播空隙表达。

## 5. 资产规则

- 同一高频动作至少准备 4 个变体：脚步、近战命中、受击、拾取。
- 变体音量随机范围不超过 ±1.5 dB，音高随机不超过 ±4%，避免卡通化。
- 广播与 Voice 必须保留可读字幕；失真不能掩盖关键任务内容。
- 音效文件名：`<world>_<source>_<action>_<variant>.wav`。
- 音乐文件名：`music_<world>_<state>_loop.ogg`。
- 环境文件名：`amb_<world>_<zone>_loop.ogg`。
- 不把未经授权的商业音乐、影视音效或来源不明的“免费素材”放入仓库。

## 6. O2 验收

- 首页、回廊、两张副本均有独立且可无缝循环的环境/音乐层。
- 玩家三种武器、受击、死亡、拾取、交互、任务完成和撤离均有反馈。
- 八类敌人/Boss 均有离屏可识别声纹和攻击预兆。
- 1280×720 桌面浏览器与手机横屏都不存在削波、爆音或加载阻断。
- 关闭音乐后，环境与玩法信息仍完整；关闭环境后，关键警报仍可感知。
- 所有文件已登记来源、许可证、作者、下载/生成日期和修改记录。
