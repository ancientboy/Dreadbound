# Dreadbound：首个垂直切片

## 目标与场景

用一局 10～15 分钟的废弃疗养院关卡，验证探索、资源压力、战斗/躲避、风险选择、任务推进和撤离结算能否形成完整循环。本阶段追求可测试的完整体验，而非正式美术或长期系统深度。

The Drifter 被投送至废弃疗养院，需要寻找三份实验记录，恢复地下室电力，随后在怪物追击下抵达出口撤离。

## 单局流程

1. 入口安全区获得基础武器、手电筒和少量补给。
2. 探索病房、护理区和维护区，收集三份实验记录。
3. 进入地下室恢复供电；该行为提高敌人压力并开放出口路线。
4. Boss 或关卡主要威胁出现，玩家返回出口。
5. 按任务、资源和事件结果结算回响碎片或因果残片，返回终末回廊。

## 首版内容清单

- 1 名角色、1 张手工制作的小型疗养院地图。
- 3 种普通敌人：The Patient、The Crawler、The Orderly。
- 1 个简单 Boss；3 种武器；3 种消耗品。
- 1 条主线任务；2 个随机事件；1 个撤离结算界面。
- 4～6 项数值清晰的永久强化。

具体武器、消耗品、Boss 和强化名称在机制通过灰盒验证后确定，避免过早扩张设定。

## 最小系统

- **玩家**：四方向移动、碰撞、生命/受击/死亡、手电筒、交互、一个武器槽和简化资源栏。
- **战斗与敌人**：基础攻击反馈；敌人待机/巡逻、发现、追击、攻击和失去目标状态；三类敌人以速度、距离和生命区分。
- **任务与关卡**：固定灰盒地图、三个记录点、供电交互、出口条件、任务跟踪、随机事件、撤离结算和最小永久强化界面。

## 实施里程碑

1. 项目框架、输入、分辨率、目录与占位界面。
2. 角色移动、相机、碰撞、灰盒地图与交互。
3. 一种武器、一种敌人、生命与死亡循环。
4. 记录、供电、出口与结算全流程贯通。
5. 补齐目标数量的敌人、装备、消耗品与事件。
6. 像素资产、音效、灯光、UI、平衡和 Web 导出验证。

任务关卡已经具备基础可玩性后，应先完成撤离结算和终末回廊局外成长，再增加第二张灾难地图。终末回廊的最小范围包括角色档案、回响碎片账户、4 项永久强化、简化整备、存档与再次出发；详细顺序见 [`progression-roadmap.md`](progression-roadmap.md)。

## 完成标准

- 新玩家无需开发者说明即可完成主线并撤离，正常局时长集中在 10～15 分钟。
- 内容节奏大致符合探索 40%、战斗/躲避 30%、风险选择 20%、叙事 10%。
- 至少一次选择明确权衡额外奖励和失去本局成果的风险。
- Web 构建在目标桌面浏览器上保持可接受的帧率、输入与可读性。
- 无阻断主线、无法撤离或结算丢失的已知问题。

## 明确不做

多人联机、3D、复杂队友 AI、程序化地图、大量装备、完整长期剧情和大规模正式美术生产不属于本切片。
