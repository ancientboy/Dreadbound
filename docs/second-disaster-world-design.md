# Dreadbound：第二灾难世界设计文档

## 立项结论

第二张地图定为 **潮没末班线（Tidefall Metro）**：一座被黑色涨潮吞没、仍在按未知时刻表运行的地下换乘枢纽。

它不是疗养院的换皮。疗养院的核心恐惧是“封闭医疗机构、供电与病理异化”；潮没末班线的核心恐惧是“被水吞噬的公共空间、不断变化的路线与错过撤离时机”。玩家需要在上升水位、暴露噪音和列车周期之间，决定继续深入还是赶上唯一可靠的撤离窗口。

本世界在完成后作为第一个真正验证动态框架可复用性的内容包，不扩张底层架构。

## 世界定位

| 项目 | 废弃疗养院 | 潮没末班线 |
| --- | --- | --- |
| 恐惧核心 | 医疗异化与封闭病房 | 溺没、迷失与被错过的末班车 |
| 关键资源压力 | 弹药、医疗与供电 | 浸水、噪音与列车时刻 |
| 主要任务 | 取回档案、恢复供电 | 定位信标、重置道岔、截获列车 |
| 空间感 | 房间、走廊、病区 | 站台、隧道、机房、淹水换乘层 |
| 撤离逻辑 | 恢复出口后主动撤离 | 在窗口期抵达正确站台登车 |
| 色彩 | 病态绿、暗红、异常青 | 黑蓝、锈橙、应急白、异常青 |
| 导演压力 | 追击与病房伏击 | 潮位、噪音、断电与车次逼近 |

## 原创背景

终末回廊捕捉到一段持续重复的“最后通勤记录”：城市遭遇不明灾变后，地下线网首先成为避难路径，随后被异常潮水从最深处反向灌满。广播仍报出车次，闸机仍吞吐无效票卡，列车会抵达不再存在的站点。

异常核心位于 **零号换乘层**。它把每一名试图离开的乘客都编码成“未完成行程”，导致整条线路无法终止。行者的任务不是清空地铁，而是切断该循环、取得核心记录，并在潮位彻底覆盖站台前离开。

不使用现实城市、真实地铁线路、既有影视或小说中的副本、角色或专有名词。

## 可玩承诺

一局目标 12～18 分钟；首版每局由 8～10 个手工房间模块组成。

- 约 35%：探索、找路、读取环境线索。
- 约 30%：躲避、战斗与噪音管理。
- 约 25%：水位、道岔、车次与风险事件决策。
- 约 10%：终端记录、广播与回廊中枢评语。

首版包含 2 个主线契约、4 个风险/支线事件、2 种普通敌人、1 个 Boss、3～5 件世界专属装备。它必须在现有 Web 性能预算内完成，不引入全局实时流体模拟或复杂潜水操作。

## 行动主线契约

### 1. 失联车次

目标：找到 2～3 个乘务信标，确认末班车正在循环的站台，并在正确时间抵达。

流程：

1. 进入检票大厅，取得潮位图或残缺时刻表。
2. 在不同分区校准 2～3 个信标。
3. 广播给出真实车次与候车站台。
4. 选择直接赶往站台，或进入可选区域取得更高价值补给。
5. 在车门关闭前登车撤离。

变体：

- 信标可能被浸水短路，需要先拉闸排水。
- 某个信标是伪信号，触发追击但会暴露捷径。
- 高噪声行动会让列车提前抵达，缩短准备窗口。

### 2. 零号道岔

目标：定位控制室、重置两处道岔，并让列车改驶至可撤离站台。

流程：

1. 找到道岔控制钥或以异常能源短接控制台。
2. 分别重置两处道岔；顺序会改变开放路线与敌人迁移。
3. 进入零号换乘层关闭循环信号。
4. 在 Boss 或追击压力下登上改道列车撤离。

变体：

- 先重置西侧道岔：开放补给间，但高水位隧道会提前淹没。
- 先重置东侧道岔：获得较安全路线，但 Boss 可在站台阶段出现。
- 使用异常装备短接：节约时间，但累积异化/噪声代价。

## 房间模块包

第一版制作 10 个模块，行动时抽取 8～10 个；每个模块有入口方向、潮位状态、任务/事件插槽、合法敌人点位与撤离可达性标签。

1. **检票大厅**：入口与基础教学；闸机、失效告示、首个时刻表。
2. **废弃商街**：资源房；玻璃碎裂、可听见远方列车。
3. **北站台**：高暴露战斗区；可能是撤离站台或伪站台。
4. **南站台**：可选绕行；可出现安全车厢残骸。
5. **淹水隧道**：移动受限、脚步噪音降低但视野恶化。
6. **信号机房**：主任务插槽；电箱、继电器与短路风险。
7. **维修走廊**：狭窄高压路线；适合伏击但必须有可读的预警。
8. **售票档案室**：叙事与支线插槽；保存“未完成行程”记录。
9. **换乘天桥**：俯视分岔，提供路线预判与远程敌人压力。
10. **零号换乘层**：Boss/核心任务区域，连接最终撤离路径。

禁止将唯一任务节点、唯一出口或唯一关键补给放进必经的深水死路；生成器必须继续满足现有连通性与撤离验证。

## 新机制：潮位、噪音、车次

### 潮位

使用离散的 **干燥 / 浸水 / 深水** 三档房间状态，不做昂贵的连续模拟。

- 干燥：正常移动与战斗。
- 浸水：移动稍慢；电器、资源与敌人布置发生变化。
- 深水：只用于少数明确标记的短路线；禁止生成强制长时间停留战斗。

潮位由行动计时、任务进度与因果链驱动。每次变化提前通过水声、广播、墙面警报与地图标记给出线索。导演只能在合法节点提升潮位，不能淹没玩家唯一撤离路径。

### 噪音

玩家的枪械、冲刺、破门、短接和部分事件产生噪音。噪音不是惩罚条，而是可解释信号：

- 让邻近房间敌人进入警戒；
- 提高“报站员”出现或列车提前进站的概率；
- 可用来故意诱开某些敌人；
- 会被行动结算记录为行为倾向。

现有敌人记忆与导演日志直接复用，不做全图同步仇恨。

### 车次窗口

撤离不是恒定出口。任务完成后会给出一个可读的窗口，例如“南站台：下一班抵达 90 秒后”。窗口期内车门会保持开启；错过后不会立即判死，而是进入一次可预期的高压补救：寻找备用道岔或等待风险更高的下一班。

## 敌人

### The Drowned（溺行者）

曾经的乘客，被潮水拖拽而非单纯复活。

- 轮廓：湿透通勤服、持续滴水、头部向一侧低垂。
- 行为：中速追击；在浸水区域移动更快；攻击前抬臂并发出吸水声。
- 定位：基础压力单位，迫使玩家在干燥地形做站位选择。
- 公平性：不会从镜头外无声突脸；水声与波纹先于攻击出现。

### The Conductor（检票员）

异常站务人员，身体与检票钳、闸机碎片融合。

- 轮廓：高瘦制服、胸前失效票卡灯、手持长柄检票器。
- 行为：低速巡逻，听见高噪声后封锁近期常用门口；发起长距离直线突刺。
- 定位：区域控制与路线改写，不作为纯高血量敌人。
- 公平性：只封锁非唯一通路；突刺前有灯光闪烁与广播杂音预兆。

### The Last Train（末班列车）

第二世界 Boss，不是一只大怪，而是一段被异常占据的列车与其“车长回声”。

阶段：

1. **进站**：站台灯闪烁，车门反复开合，生成可躲避的乘客残影。
2. **验票**：车长回声沿站台巡查，玩家需要躲避直线检票光束或破坏信号锚。
3. **离站**：潮位提升、列车开始移动；玩家可击败核心获得回收箱，也可利用短窗口撤离。

设计原则：

- Boss 奖励永远可选，击败不是通关硬条件。
- 不允许用列车实体完全封死唯一出口。
- 所有攻击区间、车门危险区与倒计时都必须在 2D 俯视角清晰读出。

## 风险事件与因果链

### 风险事件

1. **漂浮失物柜**：取走密封包可获得补给，但会割开防水层并提高后续浸水状态。
2. **错误报站**：跟随广播可发现捷径，也可能进入伪站台并引发伏击。
3. **求救车厢**：救援信号可能提供因果残片，也可能是溺行者聚集点。
4. **断路器旁路**：缩短主线时间，但立即制造高噪声和区域断电。

### 因果链样例

```text
在漂浮失物柜强行取物
→ 防水层破损
→ 下一次浸水房间转为深水
→ The Drowned 获得加速
→ 零号换乘层出现净化阀门
→ 成功关闭可获得世界专属护符
```

```text
多次使用枪械制造噪音
→ 错误报站概率提高
→ The Conductor 提前进入巡逻
→ 末班车提前到站
→ 撤离窗口缩短但 Boss 奖励候选升级
```

所有链条在后果发生前至少提供一个环境线索，并写入任务日志的“已知异常”页。

## 世界独有掉落

首版投放 4 件，均遵循“机制改变 + 清晰代价”，并接入现有品质、仓库、三选一回收箱和撤离入库规则。

| 装备 | 类别 | 效果 | 代价 |
| --- | --- | --- | --- |
| 防水脉冲腕带 | 护符 | 浸水房间中移动惩罚降低 | 干燥房间绷带效率略降 |
| 站务员哨 | 护符 | 主动制造噪音，短暂引开普通敌人 | 提高检票员警戒 |
| 绝缘撬棍 | 武器 | 对电器锚点和护甲敌人有效 | 普通攻击冷却更长 |
| 末班票根 | 异常护符 | 每局首次错过撤离窗口后获得一次补救提示 | 行动结算异化压力增加 |

不把“潮位免疫”或“直接跳过主线”作为掉落效果。

## 终末回廊中央 NPC：阈值司仪（The Threshold Curator）

### 核心定义

终末回廊中央的异常核心不只是发任务的终端，而是一个可被看见、可交互的 NPC：**阈值司仪**。

它是终末回廊为了维持行者与灾难世界之间通行而形成的“人格化接口”。它不自称神，也不拥有无条件真相；它通过归档行者的行动记录，持续构建每名玩家独立的 **行者档案**。玩家会感到它像一台冷静、长期观察自己的大脑，但故事上始终保留它的动机与判断是否可靠的悬念。

视觉：中央悬浮的异常青色多面核心，外侧有缓慢环绕的记录碎片和人形投影。对话用低饱和终端字幕呈现，避免长篇站桩演出。

### 它记忆什么

记忆使用本地、结构化、可查看的数据；不要求在线大模型，也不收集身份信息。

- 行动风格：近战/远程、噪音、探索深度、撤离倾向、风险事件选择。
- 资源习惯：弹药消耗、治疗使用时机、是否囤积或浪费补给。
- 战斗表现：受击来源、常见死亡原因、敌人类型应对成功率。
- 世界偏好：愿意进入的区域、完成的契约、反复放弃的目标。
- 成长选择：已装备物、强化、天赋方向、异常代价承受度。
- 叙事决定：是否信任司仪、是否接受其试炼、已读档案与关键分支。

不记录玩家真实姓名、聊天内容、设备标识或与游戏无关的行为。设置中必须提供“查看行者档案”“重置司仪观察”的入口。

### 三层功能

1. **回顾**：每局结算后给出一条基于真实数据的观察，例如“你在低弹药时仍倾向继续搜索，三次风险事件中有两次成功撤离。”
2. **建议**：根据当前构筑和短板，提出 1 个可拒绝的下一步建议，例如“补足生存方向：连续两局在站台追击中失血过多；建议完成一次低噪声撤离试炼。”
3. **成长计划**：两个世界稳定、天赋树开放后，为每种流派生成 3 节点的近期计划：目标、推荐世界/契约、预期收益与代价。它提出方向，玩家选择是否采纳；不会自动购买、替换装备或锁定玩法。

示例：

```text
行者档案：高风险探索 / 近战优先 / 低撤离意愿
近期计划：建立“破门者”路线
1. 在疗养院以近战完成一次主动撤离
2. 在潮没末班线关闭一处道岔且不使用枪械
3. 获得并装备一件异常护符
预期：解锁武器路线的候选天赋
代价：异常压力提高
```

### 系统边界

- 司仪只能解释、建议、解锁目标和呈现档案；不能暗改掉落、命中、敌人数值、地图种子或撤离窗口。
- 所有建议都显示其依据、奖励与代价；玩家可忽略，不会降低基础掉率或封锁主线。
- 记忆不用于跨玩家比较；单机存档中每个行者档案独立。
- 首版不接运行时 LLM；评语采用结构化标签 + 模板文案，确保离线、可测试、可本地化。
- 未来若加入玩家主动开启的生成式叙事层，必须默认关闭、明确说明网络与隐私，且不影响规则和数值。

### 实施节奏

**第二地图阶段只做 MVP：**

- 回廊中央核心可交互并显示“行动观察”。
- 存档增加 `player_profile`：6～8 个聚合指标、最近 5 局摘要、已拒绝/接受建议。
- 结算保存行动标签；司仪从规则表生成 1 条观察和 1 条可选试炼。
- UI 可查看和重置档案。

**两个世界稳定后：**

- 将行为标签映射到生存、武器、异常适应三条天赋方向。
- 加入 3 节点成长计划、世界契约推荐与人性/异化代价提示。
- 提供“采纳 / 暂缓 / 不再建议此方向”选择，避免系统反复打扰玩家。

## 开发拆分与验收

### H-Map 1：数据与灰盒

- 新建世界 ID、主题配置、房间模块标签、潮位状态、噪音事件和车次窗口数据。
- 完成检票大厅、两个站台、机房、隧道、维修走廊、档案室、天桥、零号层等 8 个灰盒模块。
- 用固定种子验证入口 → 主任务 → 站台/出口的可达性。

### H-Map 2：核心循环

- 实现“失联车次”与“零号道岔”两个任务契约。
- 实现离散潮位、噪音、车次倒计时、主动撤离和错过车次的补救分支。
- 复用小地图、迷雾、导演日志、结算和存档。

### H-Map 3：内容与压力

- 加入 The Drowned、The Conductor 与末班列车 Boss。
- 加入 4 个事件、至少 2 条因果链、4 件专属装备。
- 调整导演候选，使高压后总有可读的喘息或路线选择。

### H-Map 4：阈值司仪 MVP 与平衡

- 落地行者档案、单局观察、可选试炼和重置入口。
- 自动化覆盖至少 500 个行动种子：无死路、无必然错过撤离、任务目标齐全、档案只基于已发生事件。
- 在桌面、手机和 iPad 横屏完成完整通关；目标通关时间 12～18 分钟。
- 复查新地图与疗养院都能形成不同打法，避免“只是水面贴图变化”。

## 非目标

- 不在第二地图阶段做完整天赋树、复杂技能树、多人共享回廊或 NPC 日程。
- 不做无限世界生成、连续水体物理、潜水操作、载具驾驶或正式配音。
- 不把阈值司仪做成聊天机器人，也不让其替玩家做构筑选择。
- 不复制任何既有无限流作品的专名、剧情、强化体系或角色关系。

## 2026-07-26 P0～P5 完成记录

- **P0 发布审计门禁**：第二世界继续纳入统一场景、响应式 UI、任务配置和 Web 发布测试；真实手机与 iPad 通关保留为每次公开发布后的人工烟雾检查。
- **P1 专属威胁**：溺行者会在积水中加速并显示波纹；检票员响应行动噪音并使用有直线预警的突刺；末班列车以进站、验票、离站三阶段替代疗养院 Boss 换名。
- **P2 机制装备**：防水腕带降低浸水惩罚，站务员哨放大噪音诱敌，绝缘撬棍登记信号锚特性，末班票根首次错过列车时延长补救窗口。
