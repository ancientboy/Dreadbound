# M0–M6：Exchange & Evolution Loop

Dreadbound 的长期成长现在采用：

> 副本材料 → 兑换与拆解 → 三选一合成 → 五级强化 → 行为进化 → 心相显化

## M0：统一数据模型

- 装备继续使用稳定 ID，新增材料、词条、配方、流派、进化和心相目录。
- 六种世界材料分别绑定疗养院与末班线。
- 存档升级为 v20，并兼容 v19 及更早版本。

## M1：异常兑换所

- 常驻基础装备、世界材料与确定性轮换装备共用一个兑换列表。
- 每次成功撤离推进轮换周期；同一周期商品限购一次。
- 兑换结果、周期与购买记录写入存档，重载不会刷新。

## M2：拆解、合成与保底

- 三件同槽位、同品质、非唯一装备可合成更高一阶装备。
- 结果生成后立即保存，玩家从最多三项结果中选择，重载不能重抽。
- 世界材料改变候选词条方向；因果残片可锁定词条。
- 放弃结果会获得合成余烬并提高保底进度。
- 已装备的最后一件与世界唯一/Boss 遗物不能被误消耗。

## M3：十二战斗流派

- 坚守者：屏障反击、濒死不灭、牺牲治疗、通道控制。
- 武装师：弱点狙击、重火力压制、爆破陷阱、遗物改造。
- 共鸣者：精神感知、异常摄取、回响召唤、异化形态。
- 职业核心节点完成后，消耗 5 回响解锁流派；已解锁流派可切换。

## M4：五级强化与分支进化

- 普通强化最高五级，消耗回响碎片与合成余烬。
- 强化只提高稳定能力；进化改变构筑方向。
- 缝合镰与末班导轨枪各有三条进化分支。
- 进化要求五级、对应行为熟练度和 1 因果残片。

## M5：行为与心相

- 救援、异常选择、远程命中、群体命中和低生命战斗会记录装备熟练度。
- 心相不在商城出售，而由跨局行为事件形成。
- 当前心相直接参与角色属性，并在司仪档案显示其行为解释。

## M6：经济、迁移与验证

- 回响碎片负责常规兑换与强化。
- 合成余烬来自拆解或放弃合成，负责中高阶强化。
- 因果残片负责词条锁定、职业重构和最终进化选择。
- 世界材料负责定向候选，不替代三种核心资源。
- 自动化覆盖目录完整性、限购、合成锁定、三选一、保底、十二流派、五级强化、行为进化、心相、保存与 v19→v20 迁移。
