# Dreadbound：游戏愿景

## 一句话概念

在由人类恐惧与可能性生成的灾难世界中，玩家探索、求生并修复异常，在继续冒险和带着战利品撤离之间作出高风险选择。

## 原创世界观

世界之外存在异常设施“终末回廊”。它从人类文明的恐惧、记忆和未来可能性中生成灾难世界。被选中的“行者”必须进入这些世界，完成任务并修复异常节点。

成功归来者会获得“回响碎片”或“因果残片”，用于强化身体、装备与特殊能力；改造越深入，失去部分人性的风险也越高。力量与人性之间的张力是长期叙事和系统设计的共同主题。

本作只采用原创人物、地点、敌人、任务和成长内容，不得直接使用《无限恐怖》或其他现有作品的角色、专有名词、剧情、电影副本与具体强化内容。

## 玩家体验支柱

1. **压迫下的探索**：有限视野、未知空间和稀缺补给使每次深入都有代价。
2. **可读但危险的战斗**：敌人行为清晰，资源与站位比高频操作更重要。
3. **有后果的风险选择**：额外收益伴随失去本局成果的威胁。
4. **任务驱动的撤离**：完成关键目标并判断最佳撤离时机，而非清空地图。
5. **带代价的成长**：永久强化提供进展，同时逐步显露身体与人性的变化。

## 核心循环

进入终末回廊 → 选择装备与强化 → 进入恐怖世界 → 探索、战斗、搜集资源 → 完成主线或隐藏任务 → 继续冒险或撤离 → 结算奖励 → 永久强化 → 下一个世界。

## 内容节奏

- 40% 探索与搜集
- 30% 战斗与躲避
- 20% 风险选择
- 10% 剧情与世界观

比例用于指导关卡节奏而非硬性计时。原型应优先验证探索、资源压力和撤离判断能否形成循环。

## 主角与产品边界

玩家角色代号 **The Drifter（漂泊者）**，约 30 岁、外观偏中性。宽肩旧夹克、帆布背包、手电筒及左腕青色异常微光构成识别轮廓。

项目使用 Godot 4 + GDScript，采用 2D 俯视角四方向移动，单机优先，首先面向电脑浏览器 Web，后续支持 Windows。首阶段不做多人、3D、复杂队友 AI、程序化地图和庞大装备库；先用灰盒验证 10～15 分钟的核心体验。
