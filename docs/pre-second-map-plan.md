# Dreadbound：第二张地图前开发计划

## 目标

在立项第二个灾难世界前，把废弃疗养院从“系统原型”推进到可重复游玩的首个完整垂直切片。第二张地图必须复用稳定的角色、敌人、任务、事件、结算、成长、存档和移动端交互框架，而不是再复制一套临时代码。

## 当前基线

- **已完成**：移动、碰撞、相机、手机触控、全地图迷雾、小地图与展开地图。
- **已完成**：三份记录、恢复供电、撤离、失败、主动撤回与终末回廊往返。
- **已完成**：The Patient、The Crawler、近战、手枪、弹药、绷带和回响碎片。
- **已完成**：污染药柜、回响病房两种风险事件。
- **已完成**：结算、永久强化、三套整备和 Web 本地存档。

## 开发顺序

### 阶段 A：补齐疗养院战斗内容

1. **The Orderly**
   - 高生命、低移速、宽范围重击。
   - 攻击前必须有清晰蓄力提示，允许玩家躲避。
   - 至少放置 2 个固定遭遇点，并加入自动化行为测试。
2. **简单 Boss**
   - 恢复供电后出现，构成撤离阶段的主要压力。
   - 第一版只使用 2 个攻击模式和 1 次阶段变化。
   - Boss 不应要求清图；玩家可以战斗或寻找机会撤离。
3. **敌人组合检查**
   - Patient 负责基础追击，Crawler 负责快速逼位，Orderly 负责区域压制。
   - 调整生成位置，避免出生点围杀、门口堵死和迷雾外直接攻击。

### 阶段 B：补齐武器与消耗品

1. **第三种武器：霰弹枪灰盒**
   - 近距离多目标、高伤害、低弹量和较长冷却。
   - 与撬棍、手枪形成明确用途差异，而不是单纯数值升级。
2. **第三种消耗品：镇静剂灰盒**
   - 短时间降低敌人发现距离或提高脱离追击能力。
   - 明确显示持续时间，避免隐藏数值。
3. **整备扩展**
   - 让三套终末回廊配置能够体现新武器或消耗品取舍。
   - 保持预设式整备，不在此阶段加入复杂背包和随机词条。

### 阶段 C：完成首局引导与任务可读性

1. 新存档首局加入简短的移动、攻击、交互、绷带和地图提示。
2. 重要任务状态变化使用明显提示：记录集齐、供电恢复、Boss 出现、出口开放。
3. 未满足条件的发电机和出口必须说明缺少什么。
4. 终末回廊第一次解锁时展示一次性说明，之后不重复打断玩家。

### 阶段 D：表现层第一轮

1. 用统一灰盒/像素占位素材替换尺寸不一致的临时绘制。
2. 加入手电筒、房间明暗、电力恢复前后的环境变化。
3. 添加最小音频集合：脚步、受击、攻击、敌人警觉、拾取、供电和撤离。
4. 强化终端风格 UI 的层级、按钮反馈和小屏中文可读性。
5. 不在本阶段追求最终商业美术质量。

### 阶段 E：平衡、性能与稳定性

1. 将正常通关时间调整到 10～15 分钟。
2. 检查探索/搜集约 40%、战斗/躲避约 30%、风险选择约 20%、叙事约 10%。
3. 在常见手机与 iPad 横屏尺寸检查按钮、刘海安全区、字体和误触。
4. 减少每帧重绘、临时节点和 WebGL 资源压力，重点复测 WebGL context lost。
5. 为存档增加版本迁移测试，确保更新版本不会清空玩家成长。

### 阶段 F：完整回归与发布门槛

1. 自动化覆盖：三类普通敌人、Boss、三种武器、三种消耗品、两个事件和完整结算。
2. 连续验证以下路线：
   - 新存档 → 教学局 → 成功撤离 → 解锁回廊。
   - 回廊整备 → 再次进入 → 强化生效 → 成功结算。
   - 中途主动撤回 → 不带回本局战利品 → 返回回廊。
   - 死亡 → 失败结算 → 返回回廊。
3. GitHub Pages 部署后在手机、iPad 和桌面浏览器各完成至少一局。
4. 修复所有阻断任务、无法返回回廊、重复领奖、存档损坏和触控失效问题。

## 第二张地图立项条件

只有同时满足以下条件才开始制作第二张地图：

- 疗养院具备 3 种普通敌人、1 个 Boss、3 种武器、3 种消耗品和 2 个风险事件。
- 一局正常时长稳定在 10～15 分钟，并存在至少一次有意义的风险收益选择。
- 首局、撤离、失败、主动撤回、结算、强化、整备和再次出发全部可用。
- Web 版在目标手机、iPad 和桌面浏览器上没有已知阻断问题。
- 自动化测试与 GitHub Pages 构建持续通过。
- 新地图能够直接复用任务接口、敌人基类、拾取物、风险事件、迷雾、小地图、结算和存档系统。

## 暂不提前扩张

- 第二主角或队友系统。
- 程序化地图、多人联机和复杂基地经营。
- 大量随机装备词条、制作、耐久和交易经济。
- 大规模正式剧情、配音或最终数量的灾难世界。
